# 🔬 Multi-Agent Research System

A production-ready AI research assistant powered by LangChain, Gemini, Tavily Search, and Streamlit.

## 🌐 Live Demo

https://multi-agent-research-system-jejzavhfzpnnpv4jvsgct7.streamlit.app/

## ✨ Features

* 🌐 Search Agent for web research
* 📖 Reader Agent for deep content extraction
* ✍️ Writer Agent for report generation
* 🧐 Critic Agent for report evaluation
* 🎨 Modern Streamlit UI
* 📥 Report Download Support
* ☁️ Deployed on Streamlit Cloud

## 🏗 Architecture

User Query
↓
Search Agent
↓
Reader Agent
↓
Writer Chain
↓
Critic Chain
↓
Final Research Report

## 🛠 Tech Stack

* Python
* LangChain
* Google Gemini
* Tavily Search
* BeautifulSoup
* Streamlit
* GitHub

## 🚀 Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 🔑 Environment Variables

```env
GOOGLE_API_KEY=your_key
TAVILY_API_KEY=your_key
```
