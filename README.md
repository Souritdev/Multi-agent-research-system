# Multi-Agent Research System

An AI-powered research assistant built using LangChain, Gemini API, Tavily Search, and Streamlit.

## Features

* Search Agent for web research
* Reader Agent for content extraction
* Writer Agent for report generation
* Critic Agent for report evaluation
* Modern Streamlit UI
* Report download support

## Tech Stack

* Python
* LangChain
* Gemini API
* Tavily Search
* BeautifulSoup
* Streamlit

## Run Locally

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## Environment Variables

Create a `.env` file:

```
GOOGLE_API_KEY=your_key
TAVILY_API_KEY=your_key
```
